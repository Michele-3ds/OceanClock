# OceanClock
A relaxing clock app for Nintendo 3DS from the creator of NightClock
Hello, my name is Michele, welcome to my new clock app for Nintendo 3DS : OceanClock. 
FEATURES:
- A fully animated underwater scene serves as background for the time and date display
- Customizable clock display: choose from multiple color presets (including an animated "Rainbow Dreams" mode), four size presets, and freely reposition the clock block anywhere on screen with the combination of R + Analog
- Multiple ocean-depth color palettes for the background gradient, with adjustable inversion
- Marine life: solitary fish, schooling fish, sharks, sea turtles (with baby turtles trailing behind), anglerfish, and a rare deep-sea submersible encounter — each with independent, randomized appearance timing
- Jellyfish ecosystem:
  Free-roaming jellyfish on the bottom screen with individually randomized size,     tilt oscillation, and temperament (energetic vs. lazy personalities affecting      swim speed and behavior), tap a jellyfish to free her in the upper screen.
- Hourly events: on the hour, the screen gently clears of fauna, then a school of small fish crosses first the bottom screen and then the top screen in rigid formation, spelling out the current hour in a dot-matrix pattern.
- Alarm clock
- Countdown timer
- Screen-off mode for the bottom screen to save battery
- Instructions/Credit screen
- Persistent settings saved on app exit (Start button)
