# OceanClock
Welcome to OceanClock, a relaxing clock app for Nintendo 3DS.
Hello, I am back, my name is Michele, the creator of NightClock, welcome to my new clock app for Nintendo 3DS : OceanClock. 
- FEATURES:
- A fully animated living underwater scene.
- Customizable clock display: choose from multiple color presets (including an animated "Rainbow Dreams" mode), four size presets, and freely reposition the clock block anywhere on screen with the combination of R + Analog
- All the major formats supported for time and date.
- Multiple ocean-depth color palettes for the background gradient, with adjustable inversion
- A pair of creatures inhabit the upper screen, constantly moving, curious about the passage of other creatures...
- Marine life:
  solitary fish, schooling fish, sharks, sea turtles (with baby turtles trailing behind), anglerfish, and a rare deep-sea submersible encounter — each with independent, randomized appearance timing
- Jellyfish ecosystem:
  Free-roaming jellyfish on the bottom screen with individually randomized size spawn every ten minutes, tap a jellyfish to free her in the upper screen. tap to a free space on bottom screen to "intrigue" the nearest jellyfish to move there.
- Hourly events: At every hour change the screen gently clears of fauna, then a school of small fishes crosses first the bottom screen and then the top screen in rigid formation, spelling out the current hour in a dot-matrix pattern.
- Alarm clock
- Countdown timer
- Screen-off mode for the bottom screen to save battery
- Instructions/Credit screen
- Persistent settings saved on app exit (Start button)
